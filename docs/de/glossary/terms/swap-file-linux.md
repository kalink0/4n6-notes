# Swap File (Linux)

Die Swap File oder der Swap Space (eigene Partition) unter Linux hat dieselbe Funktion wie die Pagefile unter Windows.

Sie dient als virtueller Speicher zur Erweiterung des Arbeitsspeichers. Wenn der Arbeitsspeicher vollständig genutzt ist oder aufgrund längerer Nicht-Verwendung Daten ausgelagert werden, werden diese in die Swap File geschrieben. Dieser Prozess nennt sich Paging oder Swapping.

Die Swap File kann Spuren von laufenden Systemprozessen, geöffneten Dateien oder auch laufenden Anwendungen enthalten. Im Allgemeinen können identische Datenarten vorgefunden werden wie im Arbeitsspeicher.
