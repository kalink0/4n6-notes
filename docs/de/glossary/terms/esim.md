# eSIM

Eine eSIM (embedded SIM) ist ein fest im Gerät verbauter SIM-Chip (eUICC), auf den Mobilfunkprofile heruntergeladen werden, statt sie über eine austauschbare SIM-Karte bereitzustellen.

Ein Profil enthält dieselben Daten wie eine SIM-Karte, u. a. IMSI und ICCID; die ICCID kennzeichnet dabei das Profil, nicht den Chip. Der Chip selbst hat eine eigene, 32-stellige Kennung, die EID (eUICC Identifier). Auf einer eSIM können mehrere Profile gespeichert sein, von denen eines oder mehrere aktiv sind. Profile werden z. B. über einen QR-Code oder eine App des Mobilfunkanbieters installiert.

Aus digitalforensischer Sicht lässt sich eine eSIM nicht wie eine SIM-Karte entnehmen und mit einem SIM-Kartenleser getrennt vom Gerät auslesen. Die EID ist in den Geräteeinstellungen angegeben und steht häufig auch auf der Verpackung des Geräts.
