# BSSID

Die BSSID (Basic Service Set Identifier) ist die Kennung des Funknetzes eines einzelnen Access Points; in der Regel ist sie die MAC-Adresse seiner WLAN-Schnittstelle.

Sie ist wie eine MAC-Adresse 48 Bit lang und wird als sechs hexadezimale Bytes geschrieben (z. B. 00:1A:2B:3C:4D:5E). Bietet ein Access Point mehrere WLANs oder Frequenzbänder (z. B. 2,4 und 5 GHz) an, verwendet er dafür jeweils eine eigene BSSID. Ein WLAN mit mehreren Access Points hat daher eine SSID, aber mehrere BSSIDs.

Aus digitalforensischer Sicht ist die BSSID eines fest installierten Access Points an einen Ort gebunden, die BSSID eines mobilen Hotspots (z. B. eines Smartphones) dagegen nicht.
