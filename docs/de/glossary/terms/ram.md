# RAM / Arbeitsspeicher

Arbeitsspeicher, auch häufig als RAM (Random Access Memory) bezeichnet, ist flüchtiger Speicher. Dies bedeutet, dass die Daten in diesem Speicher sich schnell ändern, je nachdem, was auf einem Computer ausgeführt wird, und dass die Daten verloren gehen, wenn man den Computer ausschaltet.

Potentiell können sich Daten im RAM befinden, die nicht zwingend innerhalb des Dateisystems zu finden sind. Zum Beispiel können sich Schlüssel zum Öffnen verschlüsselter Container, angesurfte Internetseiten in Private-Tabs oder Spuren ausgeführter Schadsoftware im RAM befinden.
