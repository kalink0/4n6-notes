# Root

Root ist auf unixartigen Systemen wie Linux, macOS oder Android das Benutzerkonto mit uneingeschränkten Rechten (Benutzer-ID 0); „Rooten“ bezeichnet bei Android-Geräten das Erlangen dieser Rechte, die dem Nutzer normalerweise nicht zur Verfügung stehen.

Mit Root-Rechten sind Zugriff auf das gesamte Dateisystem, auch auf die Daten anderer Apps, und Änderungen am System möglich. Ein entsperrter Bootloader wird beim Gerätestart mit einem Hinweis angezeigt; manche Hersteller vermerken das Entsperren zusätzlich dauerhaft im Gerät.

Aus digitalforensischer Sicht verändert Rooten das System. Spuren sind z. B. ein entsperrter Bootloader oder installierte Apps zur Verwaltung der Root-Rechte. Bei einem gerooteten Gerät ist ein weitergehender Zugriff möglich, z. B. auf das gesamte Dateisystem.
