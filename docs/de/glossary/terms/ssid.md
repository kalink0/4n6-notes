# SSID

Die SSID (Service Set Identifier) ist der Name eines WLANs.

Die SSID ist frei wählbar und bis zu 32 Byte lang. Bei einem versteckten WLAN lässt der Access Point die SSID in seinen regelmäßigen Kennungssignalen (Beacons) leer; übertragen wird sie dennoch, sobald sich ein Gerät mit dem WLAN verbindet. Ein WLAN mit mehreren Access Points oder Frequenzbändern (z. B. 2,4 und 5 GHz) hat eine SSID, aber mehrere BSSIDs.

Aus digitalforensischer Sicht identifiziert die SSID allein ein WLAN nicht eindeutig, da derselbe Name von vielen Netzen verwendet werden kann, z. B. Standardnamen von Routern oder Hotspots einer Kette.
