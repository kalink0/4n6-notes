# IMSI

Die IMSI (International Mobile Subscriber Identity) ist eine eindeutige Kennung eines Mobilfunkteilnehmers im Mobilfunknetz. Sie wird auf der SIM-Karte bzw. im eSIM-Profil gespeichert und ist entscheidend für die Authentifizierung und Identifikation im Netzwerk.

Aufbau:

- **MCC (Mobile Country Code, 3 Ziffern):** Land des Mobilfunkbetreibers (z. B. 262 = Deutschland)
- **MNC (Mobile Network Code, 2–3 Ziffern):** Mobilfunknetz/Anbieter (z. B. 01 = Telekom)
- **MSIN (Mobile Subscriber Identification Number, bis zu 10 Ziffern):** Eindeutige Teilnehmernummer
