# Dateiendung

Die Dateiendung ist der Teil des Dateinamens nach dem letzten Punkt (z. B. `.jpg`, `.docx`) und kennzeichnet üblicherweise das Dateiformat.

Windows wählt anhand der Dateiendung das Programm aus, mit dem eine Datei geöffnet wird, und blendet bekannte Endungen im Explorer standardmäßig aus. Die Endung ist Teil des Dateinamens und lässt sich beliebig ändern, ohne dass sich der Inhalt der Datei ändert. Bei doppelten Endungen wie `rechnung.pdf.exe` wird bei ausgeblendeten Endungen nur `rechnung.pdf` angezeigt. Unter Linux und macOS sind Dateiendungen weniger verbindlich; viele Dateien haben dort keine.

Aus digitalforensischer Sicht können Dateiendung und tatsächlicher Dateityp (Dateisignatur) voneinander abweichen. Eine Abweichung kann auf eine umbenannte Datei hindeuten.
