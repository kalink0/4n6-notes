# IMEI

Die IMEI (International Mobile Equipment Identity) ist die eindeutige Seriennummer eines Mobilgeräts. Wobei die IMEI pro SIM-Steckplatz vergeben wird - pro SIM-Steckplatz (einschließlich eSIM) existiert eine IMEI.

Die IMEI kann zur Identifikation von Geräten verwendet werden.

Aufbau:

- **TAC (Type Allocation Code, 8 Ziffern):** Gerätetyp/Hersteller
- **SNR (Serial Number, 6 Ziffern):** individuelle Gerätekennung
- **Checkdigit (1 Ziffer):** Prüfziffer nach Luhn-Algorithmus
