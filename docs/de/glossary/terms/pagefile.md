# Pagefile

Die Pagefile (im Deutschen auch Auslagerungsdatei genannt) existiert in MS-Windows-Systemen. Es ist eine versteckte Systemdatei, normalerweise im Root-Verzeichnis der Systemfestplatte mit dem Namen *pagefile.sys*.

Sie dient als virtueller Speicher zur Erweiterung des Arbeitsspeichers. Wenn der Arbeitsspeicher vollständig genutzt ist oder aufgrund längerer Nicht-Verwendung Daten ausgelagert werden, werden diese in die Pagefile geschrieben. Dieser Prozess nennt sich Paging oder Swapping.

Die Pagefile kann Spuren von laufenden Systemprozessen, geöffneten Dateien oder auch laufenden Anwendungen enthalten. Im Allgemeinen können identische Datenarten vorgefunden werden wie im Arbeitsspeicher.
