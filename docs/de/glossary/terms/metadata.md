# Metadaten

Metadaten sind strukturierte Daten, die Informationen über andere Daten enthalten. In der digitalen Forensik spielen Metadaten eine zentrale Rolle, da sie wertvolle Hinweise zur Herkunft, Veränderung und Nutzung digitaler Objekte liefern.

Man kann zwei Arten von Metadaten unterscheiden:

1. Embedded Metadata oder File-based Metadata

   Sind in der Datei/dem digitalen Objekt selbst gespeichert - Beispiel: EXIF-Daten einer JPG-Datei
2. Associated Metadata oder System Metadata

   Liegen in einer separaten Struktur vor, außerhalb der Datei - Beispiel: Zeitstempel im Dateisystem für eine Datei

Beispiele von Metadaten sind:

- Dateisystem-Metadaten (z. B. Zeitstempel, Speicherpfad)
- Dokumenten- und Bild-Metadaten (z. B. EXIF-Daten von Bildern, Änderungshistorie von Word-Dokumenten)
- E-Mail-Metadaten (z. B. Absender, Empfänger, Betreff, Zeitstempel, Transportweg)
