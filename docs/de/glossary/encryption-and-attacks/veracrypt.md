# VeraCrypt

VeraCrypt ist eine kostenlose, quelloffene Software zur Festplattenverschlüsselung, die „on-the-fly“ (also in Echtzeit) arbeitet. Das Programm entstand als Fork des mittlerweile eingestellten TrueCrypt-Projekts und wurde mit zahlreichen Sicherheitsverbesserungen und Optimierungen weiterentwickelt.

Aus digitalforensischer Sicht kann gesagt werden, dass bei einem ausreichend komplexen Passwort keine bekannten Möglichkeiten bestehen, Zugriff auf die Daten innerhalb eines geschlossenen VeraCrypt-Volumes ohne das Passwort zu erlangen.

Passwortangriffe, welche versuchen mittels Ausprobieren von Passwörtern Zugriff auf die Daten im VeraCrypt-Volume zu erlangen, können je nach Komplexität des Passworts mehrere Jahrzehnte bis zum Erfolg benötigen.
