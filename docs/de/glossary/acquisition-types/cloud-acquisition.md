# Cloud-Sicherung

Bei einer Cloud-Sicherung werden Daten gesichert, die nicht auf einem Gerät, sondern bei einem Online-Dienst gespeichert sind, z. B. bei Apple (iCloud), Google oder Microsoft.

Der Zugriff erfolgt entweder mit den Zugangsdaten oder auf dem Gerät gespeicherten Anmelde-Token des Nutzers oder über eine Herausgabe der Daten durch den Anbieter.
Aus digitalforensischer Sicht kann eine Cloud-Sicherung Daten enthalten, die auf dem Gerät nicht mehr vorhanden sind, z. B. Gerätebackups, ältere Versionen von Dateien oder synchronisierte Daten anderer Geräte desselben Kontos. Ende-zu-Ende-verschlüsselte Daten können ohne die Schlüssel vom Gerät des Nutzers nicht gelesen werden. Eine Anmeldung kann den Nutzer benachrichtigen oder eine Zwei-Faktor-Authentifizierung auslösen, und die Daten können sich während der Sicherung durch Synchronisation weiterhin ändern.
