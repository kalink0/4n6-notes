# Physische Sicherung

Bei einer physischen Sicherung wird eine 1:1-Kopie eines Datenträgers erstellt. Sie beinhaltet auch nicht allozierte und nicht initialisierte Speicherbereiche, in denen zuvor existierende Daten vorliegen können.
