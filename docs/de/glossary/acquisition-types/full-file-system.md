# Full File System Sicherung

Bei einer Full-File-System-Sicherung (FFS) werden alle Dateien des Dateisystems eines Mobilgeräts gesichert. Sie ist die möglichst vollständige Sicherung moderner Mobilgeräte.  
Nicht allozierte und nicht initialisierte Speicherbereiche sind nicht enthalten.
