# Before First Unlock (BFU) Sicherung

Bei einer BFU-Sicherung wird ein Mobilgerät gesichert, das seit dem letzten Neustart noch nicht entsperrt wurde.

Eine BFU-Sicherung enthält nur wenige vom Nutzer erzeugte Daten.
