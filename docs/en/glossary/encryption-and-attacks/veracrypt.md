# VeraCrypt

VeraCrypt is free, open-source disk encryption software that works "on the fly" (i.e. in real time). The program was created as a fork of the now discontinued TrueCrypt project and has been developed further with numerous security improvements and optimisations.

From a digital forensics perspective, it can be said that with a sufficiently complex password there are no known ways to gain access to the data within a locked VeraCrypt volume without the password.

Password attacks, which try to gain access to the data in the VeraCrypt volume by trying out passwords, can take several decades to succeed, depending on the complexity of the password.
