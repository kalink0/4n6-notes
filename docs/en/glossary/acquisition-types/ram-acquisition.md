# RAM Acquisition

In a RAM acquisition, the contents of the main memory of a running system are secured.

Since main memory is volatile, the acquisition must generally be done before the system is restarted.

From a digital forensics perspective, a RAM acquisition can contain data that is not present on the storage medium or only in encrypted form, e.g. running processes, network connections, keys of encrypted volumes or content from private browser windows. The main memory keeps changing during the acquisition, so the acquisition does not represent a single point in time and cannot be repeated.
