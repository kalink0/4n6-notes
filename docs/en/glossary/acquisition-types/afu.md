# After First Unlock (AFU) Acquisition

In an AFU acquisition, a mobile device is acquired that has been unlocked at least once since the last restart but is locked at the time of acquisition.

On Android devices, it covers almost all user data. On Apple devices, data that the operating system or the respective app additionally protects while the device is locked is missing, e.g. health data and emails of the Apple Mail app; location data is only partially included.
