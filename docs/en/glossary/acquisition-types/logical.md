# Logical Acquisition

Depending on how it is carried out, a logical acquisition only contains certain data.

In the case of mobile devices, these are certain data types and apps. System data and geodata are not included for mobile devices; access and health data on Apple devices only in an encrypted backup.

In all other cases, these are the files accessible via the file system or a selection of them.
