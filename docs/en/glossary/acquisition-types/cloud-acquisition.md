# Cloud Acquisition

In a cloud acquisition, data is secured that is stored not on a device but with an online service, e.g. Apple (iCloud), Google or Microsoft.

Access takes place either with the user's credentials or sign-in tokens stored on the device, or through the provider handing over the data.
From a digital forensics perspective, a cloud acquisition can contain data that is no longer present on the device, e.g. device backups, older versions of files or synchronised data from other devices of the same account. End-to-end encrypted data cannot be read without the keys from the user's device. Signing in can notify the user or trigger two-factor authentication, and the data can keep changing during the acquisition due to synchronisation.
