# Root

On Unix-like systems such as Linux, macOS or Android, root is the user account with unrestricted privileges (user ID 0); on Android devices, "rooting" means gaining these privileges, which are normally not available to the user.

With root privileges, access to the entire file system, including the data of other apps, and changes to the system are possible. An unlocked bootloader is indicated by a notice when the device starts; some manufacturers additionally record the unlocking permanently in the device.

From a digital forensics perspective, rooting modifies the system. Traces are, for example, an unlocked bootloader or installed apps for managing root privileges. On a rooted device, more extensive access is possible, e.g. to the entire file system.
