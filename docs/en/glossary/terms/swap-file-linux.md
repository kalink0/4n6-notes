# Swap File (Linux)

The swap file or swap space (separate partition) on Linux has the same function as the pagefile on Windows.

It serves as virtual memory to extend the main memory. When the main memory is fully used, or when data is paged out because it has not been used for a longer time, this data is written to the swap file. This process is called paging or swapping.

The swap file can contain traces of running system processes, open files or running applications. In general, the same kinds of data can be found as in main memory.
