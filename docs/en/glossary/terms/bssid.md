# BSSID

The BSSID (Basic Service Set Identifier) is the identifier of the wireless network of a single access point; it is usually the MAC address of its Wi-Fi interface.

Like a MAC address, it is 48 bits long and written as six hexadecimal bytes (e.g. 00:1A:2B:3C:4D:5E). If an access point offers several Wi-Fi networks or frequency bands (e.g. 2.4 and 5 GHz), it uses a separate BSSID for each. A Wi-Fi network with several access points therefore has one SSID but several BSSIDs.

From a digital forensics perspective, the BSSID of a fixed access point is tied to a location, whereas the BSSID of a mobile hotspot (e.g. a smartphone) is not.
