# IMSI

The IMSI (International Mobile Subscriber Identity) is a unique identifier of a mobile subscriber in the mobile network. It is stored on the SIM card or in the eSIM profile and is essential for authentication and identification in the network.

Structure:

- **MCC (Mobile Country Code, 3 digits):** country of the mobile network operator (e.g. 262 = Germany)
- **MNC (Mobile Network Code, 2–3 digits):** mobile network/operator (e.g. 01 = Telekom)
- **MSIN (Mobile Subscriber Identification Number, up to 10 digits):** unique subscriber number
