# Metadata

Metadata is structured data that contains information about other data. In digital forensics, metadata plays a central role, as it provides valuable clues about the origin, modification and use of digital objects.

Two kinds of metadata can be distinguished:

1. Embedded metadata or file-based metadata

   Stored in the file/the digital object itself - example: EXIF data of a JPG file
2. Associated metadata or system metadata

   Stored in a separate structure, outside the file - example: timestamps in the file system for a file

Examples of metadata are:

- File system metadata (e.g. timestamps, storage path)
- Document and image metadata (e.g. EXIF data of images, revision history of Word documents)
- Email metadata (e.g. sender, recipient, subject, timestamps, transport route)
