# Pagefile

The pagefile (also called paging file) exists in MS Windows systems. It is a hidden system file, usually in the root directory of the system drive, named *pagefile.sys*.

It serves as virtual memory to extend the main memory. When the main memory is fully used, or when data is paged out because it has not been used for a longer time, this data is written to the pagefile. This process is called paging or swapping.

The pagefile can contain traces of running system processes, open files or running applications. In general, the same kinds of data can be found as in main memory.
