# File extension

The file extension is the part of the file name after the last dot (e.g. `.jpg`, `.docx`) and usually indicates the file format.

Windows uses the file extension to choose the program with which a file is opened, and hides known extensions in Explorer by default. The extension is part of the file name and can be changed freely without changing the content of the file. With double extensions such as `invoice.pdf.exe`, only `invoice.pdf` is displayed when extensions are hidden. On Linux and macOS, file extensions are less binding; many files there have none.

From a digital forensics perspective, the file extension and the actual file type (file signature) can differ. A mismatch can indicate a renamed file.
