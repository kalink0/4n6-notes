# RAM / Main Memory

Main memory, often also called RAM (Random Access Memory), is volatile memory. This means that the data in this memory changes quickly, depending on what is running on a computer, and that the data is lost when the computer is switched off.

RAM can potentially contain data that cannot necessarily be found in the file system. For example, keys for opening encrypted containers, websites visited in private tabs or traces of executed malware may be in RAM.
