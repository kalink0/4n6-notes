# Wiping

Wiping refers to the secure deletion of individual files or entire storage media. While in a regular deletion the actual data is only marked as deleted and thus initially remains on a storage medium, wiping triggers an overwrite of the data (e.g. with zeros). Recovery of overwritten data is not possible on modern storage media.

In military or high-security environments, data is also overwritten several times with different values (first zeros, then ones, then random). The wiping algorithms are selected according to the protection requirements of the data.
