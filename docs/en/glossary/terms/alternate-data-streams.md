# Alternate Data Streams

Alternate Data Streams (ADS) are a feature of the NTFS file system that makes it possible to attach one or more additional data streams to a file alongside its actual content. The main data stream contains the visible content of the file, for example a Word document and its content, while ADS can store additional data – for example metadata or other information – that remains invisible to standard applications.

These hidden data streams can be created and read with special commands and tools. ADS can be used both for legitimate purposes (e.g. to store the Zone.Identifier of downloaded files) and for malicious purposes (e.g. to hide malware).
