# Parsing

In digital forensics, parsing, also called syntactic analysis, refers to the process in which raw data is analysed and converted into a structured or human-readable form. File systems, memory images, network traffic, log files, SQLite databases or other data sources are interpreted in order to extract relevant information.

This makes it possible to make available existing metadata, for example on the files present in the file system.

Examples of parsing are: file system parsing, registry parsing, log and artifact parsing, network parsing (PCAP files).
