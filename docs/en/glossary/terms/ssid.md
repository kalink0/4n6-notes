# SSID

The SSID (Service Set Identifier) is the name of a Wi-Fi network.

The SSID can be chosen freely and is up to 32 bytes long. With a hidden Wi-Fi network, the access point leaves the SSID empty in its regular identification signals (beacons); it is still transmitted as soon as a device connects to the network. A Wi-Fi network with several access points or frequency bands (e.g. 2.4 and 5 GHz) has one SSID but several BSSIDs.

From a digital forensics perspective, the SSID alone does not uniquely identify a Wi-Fi network, as the same name can be used by many networks, e.g. default router names or hotspots of a chain.
