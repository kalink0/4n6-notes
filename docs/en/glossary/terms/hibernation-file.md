# Hibernation File

The hibernation file exists in MS Windows systems. It is a hidden system file, usually in the root directory of the system drive, named *hiberfil.sys*.

The file serves to store the content of the main memory on the hard disk when the system goes into hibernation. This makes it possible to quickly restore the system and application state for the user when the system is switched on again.

The file potentially contains information on open programs – browser tabs of an incognito session can also be included – running processes and services and, for example, unsaved documents.
