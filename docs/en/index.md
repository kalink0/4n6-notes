# 4n6 Notes

A collection of information on Digital Forensics.

Always work in progress – there is always something new to discover.

## Contents

### [Artifacts](artifacts/index.md)

Descriptions of artifacts of all kinds. Overview of their meaning, sources, key facts and tools/scripts for processing.

### [Deep Dives](deep-dives/index.md)

Analyses and details on, for example, file systems, file formats and timestamps. Everything that is not specifically an artifact or would be too much for a single artifact description.

### [Glossary](glossary/index.md)

Glossary with descriptions of terms in digital forensics, for example as text blocks for use in reports.
## Content status

Pages marked **Not reviewed** are drafts that have not been reviewed yet. They are marked with an icon in the navigation. Sections without content are marked “Noch kein Inhalt.” (no content yet).

## Languages

Pages can be written in any of the site's languages, currently German and English; most of them exist in German only so far. All language versions of a page are equal; further versions and languages are added gradually. If a page does not exist in a language, another version is shown – English first, otherwise German – and marked accordingly.
